# Синхронизация полки

Метаданные (список книг, прогресс, коллекции, закладки/заметки) хранятся в PocketBase.  
Файлы PDF/EPUB — только в браузере (IndexedDB) или Google Drive.

## Как работает

1. После входа клиент делает `pullAndMerge`, затем пушит локальные изменения.
2. Книга узнаётся по **SHA-256** файла (`contentHash`) или `driveFileId`.
3. На новом устройстве в полке появляются «облачные» карточки без файла (бейдж «нет файла»). Импорт того же файла склеивает прогресс и заметки.
4. Конфликты: last-write-wins по `updatedAt` / `meta_updated_at`.

## Коллекции PB

- `books` — метаданные (+ `content_hash`, `drive_file_id`, `reading_status`, `collection_ids`, …)
- `library_collections` — коллекции пользователя
- `annotations` — JSON blob на книгу

## UI

В сайдбаре библиотеки: статус sync + кнопка «Обновить» (только для залогиненных).
