# Обзор проекта

## Что это

**Étagère** — веб-читалка PDF и EPUB с «полкой» книг, заметками (выделения, цитаты, закладки, рукописный слой) и импортом файлов **из Google Drive**.

Книги хранятся **локально в браузере** (IndexedDB). PocketBase отвечает за аккаунты, подписку и серверную логику (письма, рассылка).

## Стек

| Слой | Технология |
|------|------------|
| Frontend | Next.js 16, React 19, TypeScript |
| Состояние | Zustand |
| Локальное хранилище | IndexedDB (`src/lib/storage/local.ts`) |
| PDF | pdf.js (`pdfjs-dist`) |
| EPUB | epub.js (`epubjs`) — ссылки, сноски, картинки |
| Поиск в книге | MiniSearch по извлечённому тексту (клиент) |
| Backend | PocketBase (auth, subscriptions, newsletter) |
| Почта | nodemailer + PHP relay на Reg.ru |

## Пользовательский сценарий

1. Регистрация → письмо с подтверждением email.
2. Вход → полка книг.
3. **Добавить с Google Drive** — выбор PDF/EPUB в Google Picker → книга на полке.
4. Альтернатива: загрузить PDF/EPUB с компьютера (кнопка «Добавить книгу»).
5. Открыть книгу → читалка с заметками, закладками, поиском.

## Что сознательно не делает Drive

- **Не** синхронизирует книги обратно на Drive (старый режим «бэкапа» убран).
- **Не** читает произвольные файлы по ссылке без подтверждения в Picker (scope `drive.file`).
- **Не** видит все файлы на Drive — только те, что пользователь выбрал в окне Google.
